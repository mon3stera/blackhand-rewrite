**怎么做**
1. 银河编辑器里打开 `C:\Users\Administrator\Desktop\bh-test.SC2Map`
2. 菜单 Test Document（或直接告诉我，我发命令启动）
3. 进游戏后等 25 秒，屏幕右侧出现三个按钮：**增援 / 重装 / 精英**
4. 点一下"**增援**"

**预期现象**：对话框消失，玩家 1 多出 2 个陆战队员（在镜头中心附近）。
**我会自动确认**：点完后我从银行文件读 `verify.SC2Bank`，里面应该出现
`<Section name="Buff1"><Key name="buffs"><Value int="1"/>`。
**如果没反应**，也请告诉我——那说明"事件 + 条件"这条路有坑，我需要换方案（例如用键盘输入选 buff）。
