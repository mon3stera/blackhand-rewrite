## 一、新增角色

### 影武者 —— 中立 · 致命

隐于市井的刺客，无声无息，专为灭口而行。

- 每晚选择**两名玩家**：**目标一**（你要跟踪的人）、**目标二**（决定你今晚怎么动手），你会得知目标一的**真实去向**。
- **两种攻击模式**，用 `-on` / `-off` 或行动面板的「开关」按钮随时切换，每夜开始会私密提示当前模式：
  - **模式一**：若目标一当晚访问了目标二，则你出手对付目标一（无视无敌和救治）。
  - **模式二**：你出手对付目标一当晚访问的那个人；目标一没有行动，则对付目标一。
- 如果目标一的目标是你，你会直接对付目标一（上门者必被反击）。
- 模式一固定无视无敌与救治；模式二默认尊重，房主可在角色选项里开成「追击无视无敌和救治」。
- **目标一可以被交换，目标二不能**：女巫控制你时直接替换目标一，欺骗者、巴士司机这类换向效果同样生效；目标二无法被任何方式交换。
- 攻击有专属夜间演出：出场语音 → 全场破风声红字 → 目标收到私信；两种模式下的死亡描述不同。
- 取胜时有专属结算画面。

### 观察者 —— 城镇

沉默的夜行者，常年在屋顶与窗棂之间穿行，注视着小镇的每一扇门。

- 每晚观察一名玩家（**可以观察自己**），天亮时得知昨晚有哪些角色访问了目标。
- 不会死在退伍军人的警戒之下。
- 侦探类角色的线索里会提到他。

### 天选者 —— 中立 · 致命

众神遗落人间的执行者，以天雷涤荡罪恶。

- 每晚对一名玩家降下**雷击**（默认 3 次；房主可在选项里开成 **4 次**或 **5 次**）。雷击无视无敌和救治。
- 雷击生效前可以输入 `-guess <角色拼音>` 猜测目标身份；**猜测与当时选中的雷击目标绑定**，换目标要重新猜，输入 `-guess`（不带参数）取消猜测。
- **猜对之后的次日**：当你被判处有罪时，会向全场揭示你的身份并将你释放；该天剩余时间内你无法再被投票。
  - 注意：只有**真的会被判有罪**时才会揭示。真无罪或平票时不会暴露身份，当天仍然可以被再次提名——所以猜对不等于暴露。
- **洞察**：猜对两次额外获得一次雷击。
- 夜间神罚演出重做：雷声 + 语音，等语音播完红字才落下；被雷击者的死亡描述有两种。
- 取胜时有专属结算画面。

### 堕落审判者 —— 中立 · 致命（补完）

原图这个角色当时只写了半截，现在补完了。

- 补齐名称、描述、探员线索、夜间无敌开关、夜晚固定镜头。
- 修复平票判决几乎永远不会执行的问题。
- 图鉴「犯罪可能」与其他角色一致显示「无」（他实际不会留下案底）。

## 二、新增预设（开局变体菜单）

| 预设 | 说明 |
|---|---|
| **随机：捕风捉影** | 至少一名观察者 + 一名影武者，四档子变体 A–D 随机 |
| **随机：大审判** | 固定一名堕落审判者，四档子变体 A–D（探员 / 义警 / 狱警 / 市长）|
| **随机：天谴** | 固定一名天选者，四档子变体 A–D；D 档另固定一名医生与两名瘟疫散布者 |

三个预设都是**锁定型**：采纳后面板显示 `???`，房主无法手动增删改角色，阵容在开局时揭晓。

另外，**影武者、天选者、堕落审判者这三个角色无法被随机抽中**，只会在上述预设或房主自设的阵容里出现。

## 三、机制与平衡

- **中立致命的胜利条件放宽**：三合会 + 黑手党 **≤ 1** 即可取胜（此前要求两家都为 0，导致中立致命几乎无法赢）。
- **退伍军人现在是真正的不能被限制了**：角色卡一直写着「你无法被限制」，但原图只有文案、没有实现，限制效果照样能落到他身上；二改把实现补上了。
- **瘟疫散布者**：修掉双段结算问题——现在访问瘟疫散布者会正常只计算一层毒素，当夜刚被感染的玩家不会再立刻恶化一层。
- **系命人**：系命人的效果对瘟疫致死的目标可以生效了（此前会绕过羁绊）。
- **警长新增三个「可查出 X」开关**：影武者 / 天选者 / 堕落审判者（默认开启）。
- **天选者的免死不再等于暴露**：只有会被判有罪时才揭示身份，无罪与平票不揭示、当天可被再次投票。

## 四、界面 · 文案 · 视觉

- **名字可以取斜体了**：取名时写 `-<i>名字</i>` 即可（免费）。
  - 纯拉丁名字使用内置的衬线斜体字面，含中文的名字自动用游戏字体合成斜体，**不会出现方框**。
  - 斜体名字会跟随公屏放大一起变大，不会被钉在小号字上。
- **预设阵容列表顺序统一**：城镇 → 黑手党 → 三合会 → 中立致命 → 中立邪恶 → 中立温和；同一阵营内按 固定位 → 城镇随机 → 保护 → 调查 → 政府 排列，**相同角色相邻**。疯人焚尸场、中世纪系列等原图预设已一并重排。
- **角色卡与图鉴**：影武者、天选者、观察者、堕落审判者全部收录进帮助面板，各有专属卡片底色与特性行。
- **死亡信息**：影武者与天选者的死亡描述改为随机抽取，不再每次都是同一条。
- 统一了自加文本里的省略号写法与角色名渐变色的格式。
