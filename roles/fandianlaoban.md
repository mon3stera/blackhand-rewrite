# 饭店老板（城镇·商户）设计稿

角色号：1/36　拼音：fandianlaoban　spec：`roles/fandianlaoban.json`
状态：代码已落（10–14 步完成，lint 全绿）；待打包 + 生存者恩惠的投票结算。

## 能力

每个夜晚二选一：

```
在家做饭    不出门，自己多做一份「食物」，库存 +1
出门送饭    登门给一名玩家一份「食物」，库存 -1
```

初始持有 2 份食物。

## 食物与票权

- 每持有一份食物，该角色**白天投票权 +1**，不分有罪无罪；两份就是 +2。
- **这份加成对饭店老板自己无效**：老板手上无论囤了几份，他的投票权永远是 1，
  除非票数被别的角色（市长、主教一类的外部增幅）抬起来——外部增幅照常算，
  只有「食物换来的那部分」对他自己不生效。
  代码上就是 `if (角色 != 1/36) 票权 += gv_fdFood[p];`
- 送出去的饭**当夜就到对方手上，第二个白天开始生效**（第一晚送，第二白天就能加成）。
- 食物跟着人走：
  - 被**击杀**→ 击杀者夺走其全部食物，当晚播报
    「一名杀人犯在行使罪恶时发现了意外之喜……」
  - **自杀或被处刑**→ 食物回饭店老板手里，当晚播报
    「一名饭店老板摇了摇头叹了口气……」
  - 两句播报都是当晚立即发，**各只发一次**。
- 城镇角色夜间访问饭店老板可领一份（老板库存 -1）。

## 发放规则（关键）

一夜有多人来领、库存不够时：

1. 先按优先级排序：**城镇 → 黑手党 → 三合会 → 中立**；
2. 同一优先级里人比库存多 → **在这一档里随机抽**，抽中的人拿；
3. 前一档拿完，剩下的库存才轮到下一档。

> 例：老板有 2 份，当夜 3 个城镇 + 1 个黑手来领 → 三个城镇里随机两人各拿一份，黑手拿不到。

## 生存者（特殊）

- 生存者来领取**不消耗老板库存**（白贴一份）。
- **第一次**给一名城镇角色投有罪票时，结算按**无罪**算。
- 投票结果出来后播报，用城镇色：

```
一名生存者受到了城镇的恩惠，决定帮助一次好心人
```

一次性，用完即止。

## 处刑回收的「访问」语义

持有食物的人被**处刑**时，老板去收尸，这次算作**老板访问了死者**——
老板当夜的行动会因此被调查类角色看到：

```
当夜在家做饭
  侦探/观察者看到：「你的目标访问了（死者编号），然后又回来了……」

当夜外出送饭
  侦探/观察者看到：「你的目标同时访问了（死者编号）和（送饭目标）」
```

即：回收食物这件事老板躲不开被查，做饭的回程与送饭的去程都会被记进访问。

## 同夜死亡的食物归属

被抽中领饭的人当夜若被击杀，那份食物**立即转移给击杀者**（不留在死者名下，也不回老板）。

## 白天信息

白天可获知每个人手上有几份食物（私发老板）。
